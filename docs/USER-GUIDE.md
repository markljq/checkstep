## 安装与启动

1. 从 Releases 下载 `CheckStep-Setup-x.x.x.exe`
2. 双击运行安装向导，可选择安装目录（默认装到当前用户目录下）
3. 安装完成后从桌面或开始菜单启动「Check Step」

首次启动会弹出使用指引，介绍四个核心功能点，点击「开始使用」进入主界面（仅出现一次）。

- **标题栏**：切换执行 / 编辑模式、8 种主题色、深色 / 浅色主题

## 核心概念

| 层级 | 说明 | 举例 |
| --- | --- | --- |
| **项目** | 一次上线操作对应一个项目 | 「订单中台 V3.0 上线」 |
| **里程碑** | 项目内的阶段分组，按顺序排列 | 「上线前准备」「割接执行」 |
| **执行项** | 具体要做的一件事，可带备注 | 「备份生产库并校验备份」 |
| **执行步骤** | 执行项下的细粒度子任务 | 「导出全量备份 dump」 |

## 执行模式

执行模式是上线当晚的主战场，只做「勾」这一件事，界面干净无编辑按钮。

### 1. 登记完成

点击执行项**左侧圆圈**即可登记完成：

- 自动记录完成时间（精确到秒），显示在执行项下方
- 再点一次取消完成，完成时间随之清除，其下步骤勾选状态全部重置

### 2. 修改完成时间

点击已完成项下方「完成时间」旁的 ✎ 图标，弹出时间选择器：

- 可修改到分钟，秒沿用原值
- 适合补录：实际 21:30 完成但当时顾不上点，事后补记

### 3. 执行步骤

- 有步骤的执行项显示「N 个执行步骤」，点击展开
- 点击步骤行即可逐条打勾，与执行项的完成状态独立
- 全部步骤打完 ≠ 执行项自动完成——执行项由你手动登记，避免「步骤没做完却误勾」的情况

### 4. 待办悬浮定位

内容较多且视口内已经没有未执行项时，右下角会出现「待办」悬浮按钮：

- 点击后自动展开目标所在里程碑、平滑滚动到**最早的一个未执行项**并高亮闪烁 1.8 秒
- 上线长清单逐项推进时非常好用

### 5. 折叠与展开

- 点击里程碑标题行折叠 / 展开该组
- 顶部「全部折叠」「全部展开」一键收放所有里程碑

## 编辑模式

右上角切换到编辑模式后，所有维护功能亮起（Toast 会提示当前模式）。

### 项目（侧边栏）

- **新建项目**：填名称与备注，新项目排在列表最上方
- **编辑 / 复制 / 删除**：选中项目的列表项上操作；至少保留一个项目，删除有二次确认
- **复制项目**：完整复制里程碑与执行项结构，**执行状态与完成时间全部重置**——同类上线复用清单的标准做法

### 里程碑

- **新增**：内容区底部「新增里程碑」
- **编辑 / 删除**：里程碑标题行右侧按钮；删除会连带其下所有执行项与步骤，有二次确认
- **排序**：拖住标题行（或左侧把手）上下拖动，出现上/下插入指示线后松手

### 执行项

- **添加**：每个里程碑列表底部的「+ 添加执行项」
- **编辑 / 复制 / 删除**：悬停执行项显示右侧按钮；复制的执行项状态重置
- **拖拽排序与跨组移动**：
  - 拖到某执行项上/下方 → 插到该位置
  - 拖到列表空白处 → 移到该里程碑末尾
  - 拖到里程碑标题行 → 移入该里程碑末尾

### 执行步骤

- 执行项右侧 **+** 按钮：多行连续录入（回车换行继续加，适合批量粘贴整理）
- 悬停步骤行高亮，显示 ✎ 编辑 / 🗑 删除按钮
- 步骤支持逐条打勾

## 分享进度图

内容区顶部「分享进度」按钮，一键生成**纵向里程碑时间线图**：

- 里程碑自上而下按顺序排列，左侧时间轴标注当前位置（实心勾 = 全部完成，光晕圈 = 进行中）
- 执行项渲染为圆角胶囊：实心主题色 = 已完成，空心 = 未执行
- 顶部显示项目名、里程碑/执行项统计与总进度百分比
- **不包含具体完成时间**，可放心对外分享
- 配色自动跟随当前深浅主题与主题色
- 生成后可「复制图片」（直接粘贴到聊天工具）或「保存 PNG」（2 倍分辨率，适合文档汇报）

## 导入与导出

侧边栏底部「导入 / 导出」：

| 操作 | 说明 |
| --- | --- |
| JSON 备份 · 全部项目 | 导出所有项目与偏好设置，用作全量备份 / 跨设备迁移 |
| JSON · 当前项目 | 只导出当前选中的项目 |
| Markdown 清单 · 当前项目 | 生成带勾选框、完成时间、进度统计的 Markdown 文件，便于评审归档 |
| 从 JSON 文件导入… | 读取 JSON 后选择：**追加为新项目**（保留现有数据）或**替换全部数据**（有二次确认，建议先备份） |

导入时自动校验文件结构，缺失的字段（如旧数据的 `id`）会自动补齐/重生成，不合法条目会被跳过并在统计中体现。

## 外观设置

标题栏右侧：

- **主题色** 🎨：8 种配色（默认蓝 / 青绿 / 紫色 / 粉色 / 橙色 / 绿色 / 金色 / 红色），深浅色各有一套优化色值；配色同步应用到勾选、进度条、按钮与分享图
- **深浅切换** 🌙：手动切换深色 / 浅色；首次启动跟随系统

## 数据与备份

| 内容 | 位置（Windows） |
| --- | --- |
| 清单数据 | `%APPDATA%\checkstep-desktop\data\checkstep.json` |
| 运行日志 | `%APPDATA%\checkstep-desktop\main.log` |

**安全机制：**

- 每次修改立即持久化，写入为原子操作（临时文件 + 重命名），断电/崩溃不会损坏已有数据
- 数据文件损坏时自动备份为 `checkstep.json.corrupt-<时间戳>.bak` 后重建
- 卸载应用不会删除数据目录，重装后数据仍在

**建议的备份习惯：** 每次上线前用「JSON 备份 · 全部项目」导出一份存到网盘/内网共享；上线完成后把 Markdown 清单归档到项目文档库。

## 常见问题 FAQ

**Q1：数据会上传到服务器吗？**
不会。Check Step 是纯本地应用，无任何网络请求，数据只存在本机。

**Q2：换电脑怎么迁移？**
旧电脑「JSON 备份 · 全部项目」导出 → 新电脑「从 JSON 文件导入」→ 选择「替换全部数据」。

**Q3：误删了项目 / 执行项怎么办？**
应用内无法恢复（所以删除都有二次确认）。如果导出过 JSON 备份，可以导入并「替换全部数据」回滚。

**Q4：为什么复制出来的项目全是未完成状态？**
这是刻意设计——复制的定位是「清单模板」，结构保留、状态清零，直接开始下一次上线。

**Q5：为什么步骤全打完，执行项还没有勾？**
执行项的完成是手动登记的（要记录完成时间），步骤勾选只是过程跟踪。全部步骤完成后，点击执行项圆圈登记完成即可。

**Q6：能同时改同一条数据吗（多人协作）？**
不支持。Check Step 定位是单人本地工具，无协作与云同步能力。

**Q7：桌面图标显示的还是旧图标？**
是 Windows 图标缓存的缘故，注销重登或重启资源管理器（explorer.exe）即可刷新。

**Q8：完成时间显示错了能改吗？**
可以，点已完成项里的 ✎ 图标修改；精确到分钟，秒沿用原值。
